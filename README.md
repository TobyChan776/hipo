# HIPO 🦛

HIPO is a tiny daily number puzzle. Solve three math challenges using each of four numbers exactly once. No account or backend required.

## Play

Once GitHub Pages is enabled, play at https://tobychan776.github.io/hipo/.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. The site is a static HTML/CSS/JavaScript game.
